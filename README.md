
# 🔐 Vigenère UTF‑8 Verschlüsselung – PWA

Diese App ist eine **offline-fähige Progressive Web App (PWA)**.
Sie verschlüsselt und entschlüsselt Texte mit einer erweiterten UTF‑8‑Vigenère‑Methode.

## ✅ Eigenschaften
- funktioniert offline
- keine Server
- keine Datenübertragung
- lokal & sicher
- installierbar wie eine App

---

## 🪟 Windows / macOS / Linux

1. Ordner entpacken
2. Terminal im Ordner öffnen
3. Server starten:

```bash
python -m http.server 8080
```

4. Browser öffnen:
```
http://localhost:8080
```

5. „Installieren“ wählen

---

## 🤖 Android
- App im Browser öffnen
- Menü → „Zum Startbildschirm hinzufügen“

## 🍎 iOS (Safari)
- Teilen → „Zum Home-Bildschirm“

---

## 🔌 Offline-Test
- App einmal öffnen
- Internet deaktivieren
- App erneut starten

---

## 🔒 Sicherheit
- Schlüssel wird **nicht gespeichert**
- alles läuft lokal im Browser
